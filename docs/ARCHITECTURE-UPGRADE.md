- [ ] 只有设计意图、没有证据的条目，已显式标注"**未验证**"（不算通过）。
- [ ] 已确认与第 1 层（T01–T13）无冲突；有冲突处已在 §12 与 `requirements-upgrade.md` §3 对齐。

## 1. 范围与不改动项

- **填什么**：升级范围（U1–U6 + 契约 P1 必要收口）；明确不改的（数据库、云文档、卡片按钮、多份作业并存、匿名提交者查询）。
- **证据**：与 `requirements-upgrade.md` §1 非目标逐条对齐（打勾表即可）。
- **不通过**：出现非目标清单里的东西，或漏了 U1–U6 任一项。

## 2. 运行形态与双机器人隔离（审核 1）

- **填什么**：进程拓扑（升级实例 / MVP 实例）、凭据来源（**写路径与环境变量名，不写明文**）、数据根、独立测试群、日志分文件。
- **证据**：升级版发消息 MVP 零响应 + 反之亦然（≥4 条实测记录，两个群）。
- **不通过**：只换凭据、数据根仍共用；或"同群调试"只在文字里声明了隔离。

## 3. 数据层：工作空间隔离与迁移（审核 2）

- **填什么**：目录结构、文件清单、群标识来源、可读名规则、MVP 旧数据迁移步骤与**回退**步骤。
- **证据**：迁移前后逐文件对照；一次迁移失败回退演练记录。
- **不通过**：只写目录结构、没有迁移/回退演练。

## 4. 触发层：@ 门禁 / 白名单播报 / 免 @ 窗口（审核 3，重点）

- **填什么**：状态 × 消息矩阵（空闲 / 投票中 / 志愿窗口中 × 无 @ 闲聊、无 @ 纯数字、无 @ `封盘`、@ 非功能词、@ 功能词）；白名单机器可读定义；窗口开关、超时与谁关。
- **证据**：≥6 条穿透用例实测记录（清单见 `requirements-upgrade.md` §8 第 3 条）。
- **不通过**：只给设计意图；或矩阵有空格；或投票态能把非白名单消息放进来。

## 5. 指令与路由（审核 4）

- **填什么**：路由表 9 条、匹配优先级与状态优先、方向拍板的参数解析与台账落盘。
- **证据**：9 条各一条实测记录；`我们要做的方向是：X` 的回执样例 + 台账记录样例。
- **不通过**：路由条数对不上；拍板方向只回话不落台账。

## 6. 智能层双链路（审核 5，重点）

- **填什么**：分支判定点、有评分点链路、无评分点链路、**混合作业书裁决**、溯源字段落法。
- **证据**：四份 —— ① 覆盖率分母取数来源（代码位置）② 无评分点跑完的分子/分母实测 ③ 改造前后 T12 覆盖率一致的两组数字 + 复算输出 ④ 混合作业书的裁决结论。
- **不通过**：拿"不计算"和"算出来是 0"混着说；或混合作业书没裁决。

## 7. 私聊归属（审核 6）

- **填什么**：私聊绑定规则、歧义反问话术、未入群时的处理。
- **证据**：一条"双群用户私聊"实测记录。
- **不通过**：默认取第一个群、或没有歧义反问。

## 8. 变更机制（审核 7）

- **填什么**：变更类型与权限、台账字段、双向确认的状态流转、回流池与兜底分配的关系。
- **证据**：换人 / 退出 / 加入各一条完整流转记录（含台账落盘样例）。
- **不通过**：变更无留痕；或退出能单方面生效。

## 9. 失败路径与降级话术（审核 8）

- **填什么**：只 @ 无文本、文件找不到、私聊归属不明、无人志愿、LLM 超时/报错 —— 逐条的降级行为与话术。
- **证据**：逐条话术样例（须符合 U5：说人话 + 事实字段不被润色）。
- **不通过**：话术是字段拼接或公文腔。

## 10. 演示链路与保底（审核 9）

- **填什么**：演示脚本（谁 / 哪个群 / 发什么 / 期望什么 / 时长）；每条链路的**无 LLM 保底路径**。
- **证据**：一次完整彩排记录（9/18 前）。
- **不通过**：链路依赖 LLM 单点、没有保底。

## 11. 话术层实现（审核 10）

- **填什么**：哪些字段模板化锁定（人名 / 任务号 / 时间 / 数字）、哪些交给 LLM 润色、长度控制（群消息 ≤4 行）。
- **证据**：10 条真实输出 + 3 人盲评记录。
- **不通过**：事实字段走 LLM；或群消息会刷屏。

## 12. 口径一致性与排期（审核 11、12）

- **填什么**：与 D-69～D-76 的对应表；T01–T13 回归计划；冻结点；P2 开关。
- **证据**：回归执行记录表（含 3 处口径改写的理由）。
- **不通过**：口径改写在材料里没提；或排期与 `requirements-upgrade.md` §5 不一致。
